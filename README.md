## 💻 Cara Menjalankan Secara Lokal
Buka file `index.html` langsung di peramban apa pun (dobel-klik), atau jalankan local server:
```bash
npx serve .
# atau
python -m http.server 3000
```
Lalu akses di browser: `http://localhost:3000`.
